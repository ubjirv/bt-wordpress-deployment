## 装宝塔面板：一条命令，重点是记住端口

装宝塔本身只要一条命令，但装完有一件事必须马上做：去安全组放行面板端口。漏了这步，面板地址怎么刷新都打不开。

用SSH工具连上服务器（Windows用Xshell或PuTTY，Mac用自带终端，也可以直接用云控制台的网页登录）。CentOS系统执行：

bash
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec


Ubuntu或Debian的安装脚本不一样，去宝塔官网复制对应系统的命令，别混着用。

中途会提示 `Do you want to install Bt-Panel to the /www directory now?(y/n)`，输入 `y` 回车，等一两分钟。屏幕上会输出面板地址、用户名和密码，截图保存。

这里要纠正一个很多老教程还在写的过时信息：宝塔面板端口早就不是8888了。现在安装完成后会随机生成端口，面板地址形如 `https://你的服务器IP:39118/2f9e6bd7`，冒号后面是端口，末尾那串是安全入口。

接下来登录云服务器控制台，找到这台机器的安全组（或防火墙），在入方向放行这个端口，源地址填 `0.0.0.0/0`。网站要对外访问，80和443端口也一并放行。数据库的3306端口不要对公网开放。

浏览器打开面板地址登录，绑定宝塔账号，弹出的套件窗口选LNMP（Nginx+MySQL+PHP）一键安装，等五分钟左右。

## 用宝塔建站点：域名、数据库、PHP版本一次设好

建站点这一步会把WordPress要用的数据库一并建好，填的时候细心点，能省掉回头返工。

左侧【网站】→【添加站点】：

- 域名：已解析的域名就填域名；还没买域名先填服务器IP
- 根目录：保持默认
- 数据库：选MySQL，让宝塔自动创建
- PHP版本：选8.0或更高。WordPress官方要求PHP 7.4以上，新装没理由用低版本

提交后宝塔会显示站点目录、数据库名、数据库用户名和密码。这组信息下一步装WordPress要原样填进去，先存好。

站点建好后点【设置】，改两处：

伪静态。下拉选wordpress，保存。不做这步，等你在WordPress后台把固定链接改成“文章名”形式，除首页外的页面会全部404。

SSL证书。建议现在就配。可以一键申请Let's Encrypt免费证书，也可以把别处申请的证书内容粘贴进去。为什么强调“现在”：等站点有内容了再开HTTPS，WordPress后台的站点地址要从http改成https，数据库里的旧链接、主题和插件里写死的地址都得跟着处理，内容越多越麻烦。

还有一点，打算在同一台服务器上搭多个WordPress的话，每个站建库时把表前缀改成不一样的，别都用默认的wp_。多个站表前缀相同、又都开了Redis缓存，缓存键会互相覆盖，数据容易乱。单站用户碰不到这个问题。

## 部署WordPress：一键部署和手动上传怎么选

宝塔给WordPress准备了一键部署入口，也支持手动上传官方安装包。想省事选前者；想用官方最新版、或者习惯自己控制文件结构，选后者。

### 方式一：一键部署

网站列表里找到你的站点，点【设置】，里面的【一键部署】选中WordPress，确认。宝塔会自动下载并解压到站点根目录，完成后给出数据库信息。直接访问域名，就会进入WordPress安装向导。

### 方式二：手动上传

去WordPress官网下载最新中文版压缩包。宝塔【文件】里进入站点根目录（/www/wwwroot/你的域名），上传zip，解压后把wordpress文件夹里的所有文件剪切到根目录，再删掉空文件夹和压缩包。

### 安装向导

访问域名，按提示走：

1. 选简体中文
2. 填数据库名、用户名、密码——是建站点时宝塔生成的那组，不是宝塔面板的登录账号
3. 设置站点标题、管理员用户名、密码、邮箱。用户名别用admin
4. 点安装，完成后用管理员账号登录“你的域名/wp-admin”

## 装完先做这几项设置，再开始写文章

新装的WordPress，默认登录地址和默认用户名都是公开信息，不处理等于把门虚掩着。装完先花十分钟做完下面几件事。

换掉admin用户名。安装时已经用了admin的，在后台【用户】→【添加新用户】建一个新管理员，退出后用新账号登录，再把admin删掉。

保持更新。后台【更新】出现红点就点进去，WordPress核心、主题、插件都更新。更新前先在宝塔的站点里做个备份，出问题能回滚。

装个安全插件。Wordfence Security免费功能够用，装上后自动扫描一次，按提示处理；防火墙建议开“扩展保护”模式。

改掉默认登录地址。用WPS Hide Login插件，把/wp-admin改成别的路径，比如my-secret-login，改完存进浏览器书签。

## 几个容易卡住的问题

宝塔面板地址打不开？先查安全组。面板用的是随机端口，去云控制台的入方向规则里确认放行了没有，这一步错了，其他都白搭。

WordPress访问慢？三个见效最快的办法：装缓存插件（WP Super Cache）、图片压缩后再上传、砍掉不用的插件。

用域名访问需要备案吗？服务器在中国大陆就必须备案，香港和海外节点不用。

域名怎么指向服务器？在域名注册商那里加一条A记录，记录值填服务器公网IP，几分钟到几小时生效。

一键部署和手动上传有什么区别？一键部署省掉下载解压的步骤，版本跟随宝塔内置包；手动上传能第一时间用上WordPress官方最新版。

宝塔和WordPress是中文的吗？宝塔装完就是中文界面；WordPress安装时选简体中文即可，选错了在后台Settings→General里能改回来。
